# drone-mngr.github.io

The public Astro marketing site for **Drone Manager**.

Fleet and airspace operations for missions, bounded commands, telemetry, geofences, and audit.

## Development

Use Node.js 22.22.1 or newer.

```sh
npm ci
npm run dev
npm run build
```

Astro writes the production site to `dist/`. The committed GitHub Actions workflow builds pull requests and deploys the default branch to GitHub Pages.
